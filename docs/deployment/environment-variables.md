# Environment variable reference

Never commit values. `.env.example` files contain placeholders only.

## API (`apps/api`, Coolify env for the Money Money app)

| Variable | Required | Default | Notes |
|---|---|---|---|
| `DATABASE_URL` | ✓ | — | Set by compose from `POSTGRES_PASSWORD` |
| `POSTGRES_PASSWORD` | ✓ (Coolify) | — | Dedicated, generated by the provisioning script |
| `CLERK_SECRET_KEY` | ✓ | — | Clerk app `app_3LlSjoo…` (prod instance `sk_live_…`) |
| `CLERK_JWT_KEY` | | — | PEM for networkless verification |
| `CLERK_AUTHORIZED_PARTIES` | | `https://moneymoney.necookie.dev` | Allowed `azp` origins for browser tokens; native-app tokens (no `azp`) are accepted on signature + owner checks |
| `OWNER_CLERK_USER_IDS` | ✓ prod | — | Comma-separated owner Clerk user ids |
| `CORS_ORIGINS` | | web origin | Comma-separated |
| `PORT` / `HOST` | | `3001` / `0.0.0.0` | |
| `LOG_LEVEL` | | `info` | |
| `DATABASE_POOL_MAX` | | `10` | |
| `MIGRATE_ON_START` | | `false` | Container runs `migrate.js` explicitly instead |
| `RATE_LIMIT_PER_MINUTE` | | `300` | |
| `ENABLE_API_DOCS` | | `true` | `/docs`, `/openapi.json` |
| `TRUST_PROXY` | | `true` | Behind Cloudflare Tunnel |
| `APP_VERSION` | | `dev` | Reported by `/health` |
| `CLOUDFLARE_TUNNEL_TOKEN` | ✓ (Coolify) | — | For the `moneymoney-tunnel` service |
| `RCLONE_CONFIG_B64` / `RCLONE_REMOTE` | | — | Off-server backups |

## Web (`apps/web`)

| Variable | Where | Notes |
|---|---|---|
| `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY` | build env | Inlined at build |
| `CLERK_SECRET_KEY` | Wrangler secret | `wrangler secret put CLERK_SECRET_KEY` |
| `NEXT_PUBLIC_API_URL` | build env | `https://api.moneymoney.necookie.dev` |

## Mobile (`apps/mobile`, EAS environment)

| Variable | Notes |
|---|---|
| `EXPO_PUBLIC_CLERK_PUBLISHABLE_KEY` | Same Clerk app |
| `EXPO_PUBLIC_API_URL` | `https://api.moneymoney.necookie.dev` — a public URL, not a Tailscale name |

## Provisioning (`.secrets.local.env`, local only)

`COOLIFY_API_TOKEN`, `COOLIFY_URL` (default `http://necore:8000`), `CLERK_PUBLISHABLE_KEY`,
`CLERK_SECRET_KEY`, `OWNER_CLERK_USER_ID`, `CLOUDFLARE_TUNNEL_TOKEN`, `CLOUDFLARE_TUNNEL_ID`,
`CLOUDFLARE_ACCOUNT_ID`; written by scripts: `MM_POSTGRES_PASSWORD`, `COOLIFY_APP_UUID`.
Cloudflare itself is driven by `wrangler login` (OAuth).
